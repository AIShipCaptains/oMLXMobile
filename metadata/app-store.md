## Subtitle (30 chars)
Chat with your own local LLM

## Description
oMLX Mobile is the pocket front-end for your own LLM server.

Run oMLX on your Mac Studio (or any OpenAI-compatible server — LM Studio, llama.cpp, Ollama, vLLM), publish it over Tailscale or your LAN, and chat with your own models from anywhere: GLM, DeepSeek, Qwen, Llama — whatever your server hosts.

FEATURES
• Streaming responses with markdown rendering
• Multiple server profiles — tailnet URL for travel, LAN at home
• API keys kept safely in the iOS Keychain
• Live model picker and per-model load/unload (oMLX)
• Server dashboard: restart, reload settings, clear cache, live stats
• Conversation history stored on your device
• Zero trackers, zero analytics, zero third-party SDKs

PRIVACY BY DESIGN
The app connects only to servers you configure. Nothing is collected — your conversations and keys never touch any server operated by the developer.

NOTE
This app is a client. You need access to an OpenAI-compatible LLM server (such as oMLX on Apple Silicon) to use it.
